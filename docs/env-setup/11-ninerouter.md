# 9Router clinical endpoint

9Router runs on VPS `103.173.227.247`; the ASINU backend on
`36.50.176.55` calls its HTTPS API. Doctor copilot requests are generated by
ASINU, so they use the same configuration.

Set these values in the backend's persistent runtime Compose environment:

```dotenv
AI_PROVIDER_CLINICAL=9router
SYMPTOM_AI_PROVIDER=9router
DOCTOR_AI_PROVIDER=9router
NINEROUTER_ENDPOINT=https://9router.asinu.top/v1/chat/completions
NINEROUTER_API_KEY=<active 9Router API key, server-side only>
NINEROUTER_MODEL=ag/gemini-3.8-flash-low
NINEROUTER_VISION_MODEL=ag/gemini-3.8-flash-low
NINEROUTER_SUPPORTS_JSON_MODE=false
DOCTOR_AI_CHAT_MODEL=ag/gemini-3.8-flash-low
```

Recreate the backend container after changing Compose environment values.
The existing `medgemma` module and call sites are compatibility names: when
9Router is configured, old Dr7 model IDs resolve to `NINEROUTER_MODEL`.
Medication scanning uses `NINEROUTER_VISION_MODEL`; explicit nonlegacy model
overrides remain supported. Provider metadata records `9router` and the model
returned by the gateway. Missing configuration or authentication failures do
not switch these requests to OpenAI or Dr7. Existing consent and response
validation still apply. This configuration does not change the separate
OpenAI chat or speech services. New model IDs have no assumed Dr7 pricing.

Install `deploy/ninerouter-api.traefik.yml` in Traefik's dynamic directory on
VPS 103. It permits the ASINU server (`36.50.176.55/32`), the existing allowed
source (`42.116.207.209/32`), and the current local workstation
(`118.70.84.244/32`, verified 2026-11-17) to reach the two API paths;
9Router must keep `requireApiKey=true`. Dashboard Basic Auth remains on the
existing router. Do not send the dashboard password as a model API key.

Before switching, test `/v1/models` and a synthetic JSON completion from the
ASINU server with a valid API key. Test an invalid key, verify the dashboard
still requests Basic Auth, and confirm the API rejects other source IPs.
If the workstation's public IP changes, replace its `/32` entry with the newly
verified public IPv4 address. Local requests still require a valid 9Router API key.
Retain a protected copy of the previous runtime Compose file and its image
for rollback. Do not put API keys, runtime Compose contents, or patient
payloads in deployment reports.
